Chrome 扩展 Agent Skills

Chrome 扩展

这些扩展尚未上架 Chrome 网上应用店，需通过开发者模式手动加载。整个过程约 1 分钟，代码均在 GitHub 开源。

1. 下载扩展

在扩展列表点击「下载」，获得 zip。解压后应能看到 manifest.json。

提示：GitHub 下载的 zip 解压后文件夹名可能带 -main 后缀，加载时选择该文件夹即可。

2. 打开扩展管理页

在 Chrome 地址栏输入并访问：

chrome://extensions/

Edge 浏览器请访问 edge://extensions/。

3. 开启开发者模式

在扩展管理页右上角，打开「开发者模式」开关。

4. 加载扩展

点击左上角「加载已解压的扩展程序」，选择刚才解压的文件夹。

5. 更新扩展

重新下载 zip 解压覆盖原文件夹，然后在扩展管理页点击该扩展卡片上的刷新。

常见问题

提示「无法加载扩展」？
确认选择的是包含 manifest.json 的根目录，而不是 zip 文件本身。
VaultPass 没有图标？
需先运行 python scripts/generate_icons.py，详见其 GitHub README。
扩展会被自动更新吗？
开发者模式加载的扩展不会自动更新。

Agent Skills

Skill 是给 Cursor / Codex Agent 读的说明书（SKILL.md）加可选脚本。解压后放到约定目录，新开一场对话即可调用。

1. 下载

在Skills 列表点击「下载」，得到 zip 或单份 SKILL.md。

2. 放到 skills 目录

Cursor（Windows）：

%USERPROFILE%\.cursor\skills\<skill-name>\

目录里至少要有 SKILL.md。Codex 技能则放到 %USERPROFILE%\.codex\skills\<skill-name>\。

3. 新开对话

已打开的对话不一定会立刻扫到新 skill。新开一个 Agent 对话，用 skill 描述里的触发语（例如「一条龙 json.cn」）。

注意

cloudflare-manager 没有密钥？
zip 故意不含 .env。在本地自建 .env，写入 CLOUDFLARE_API_TOKEN 与 CLOUDFLARE_ZONE_ID。
website-rebuild 只有 SKILL.md？
完整脚本包较大。说明文件可先读；完整 scripts/ 需自行同步完整 skill 目录。
复刻站能当官方用吗？
不能。它们是学习件，页面上应视为非官方复刻。
