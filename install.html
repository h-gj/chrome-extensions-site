安装指南

这些扩展尚未上架 Chrome 网上应用店，需通过开发者模式手动加载。整个过程约 1 分钟，完全安全（代码均在 GitHub 开源）。

1. 下载扩展

在首页点击对应扩展的「下载」按钮，获得 zip 压缩包。解压后应能看到 manifest.json 文件。

提示：GitHub 下载的 zip 解压后文件夹名可能带 -main 后缀，加载时选择该文件夹即可。

2. 打开扩展管理页

在 Chrome 地址栏输入并访问：

chrome://extensions/

Edge 浏览器请访问 edge://extensions/。

3. 开启开发者模式

在扩展管理页右上角，打开「开发者模式」开关。

4. 加载扩展

点击左上角「加载已解压的扩展程序」，在文件选择器中找到刚才解压的文件夹并确认。

加载成功后，扩展会出现在列表中，工具栏也会出现对应图标。

5. 更新扩展

当扩展有新版本时，重新下载 zip 解压覆盖原文件夹（或解压到新目录后移除旧版），然后在扩展管理页点击该扩展卡片上的刷新按钮。

常见问题

提示「无法加载扩展」？
确认选择的是包含 manifest.json 的根目录，而不是 zip 文件本身或子文件夹。
VaultPass 没有图标？
该扩展需先运行 python scripts/generate_icons.py 生成图标，详见其 GitHub README。
扩展会被自动更新吗？
开发者模式加载的扩展不会自动更新，需手动下载新版本并刷新。
安全吗？
所有扩展源码公开在 GitHub，可自行审查。数据均存储在本地，无云端账户。
